## What you get

Three color themes for bb. Each theme has a light mode and a dark mode, and each repaints the whole app, not only the colors.

- **LCARS TNG**: orange and lavender on black glass (dark) or warm beige (light).
- **LCARS Science**: a blue science and operations palette.
- **LCARS Ten Forward**: purple and mauve.

All text colors pass WCAG AA contrast (4.5:1 or better).

## What changes on screen

- An elbow frame around the left sidebar and the right panel.
- A thick frame around the thread window, with a segmented top bar and a two-row bottom band.
- Thread rows styled as menu buttons. The open thread is a solid rounded rectangle.
- Pill buttons and badges, and flat pill caps on the bottom status bar.
- Decorative number labels and a faded starship blueprint behind the thread area, tinted by the theme.

## How to switch

1. Install the plugin.
2. Open Settings, then Appearance, and pick one of the three LCARS themes. Or run `bb theme set plugin:lcars:lcars-tng`.
3. Change light or dark mode with the usual bb mode control.

The theme ids are `plugin:lcars:lcars-tng`, `plugin:lcars:lcars-science` and `plugin:lcars:lcars-ten-forward`.

## Requirements

- bb 0.49 or later.
- The styles target bb's current interface. A bb update can change the interface and some frame pieces can stop matching.
- The plugin has no settings, no commands and no network access.
